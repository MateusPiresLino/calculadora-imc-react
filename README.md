Calculadora de IMC - React

Uma calculadora simples e eficiente para calcular seu Índice de Massa Corporal, com histórico de resultados.

🚀 Começando

1. Clone o repositório:

- git clone https://github.com/seu-usuario/calculadora-imc-react.git
- cd calculadora-imc-react

2. Instale as dependências

- npm install

3. Inicie o app

- npm start

✨ Funcionalidades
✅ Cálculo instantâneo do IMC

📊 Classificação automática (Magreza, Normal, Sobrepeso, etc.)

📅 Histórico de cálculos

📱 Design responsivo

🎨 Interface moderna e intuitiva

🛠 Tecnologias
React (Hooks)

CSS Modules

JavaScript ES6+

📝 Como usar
Insira seu peso (kg)

Insira sua altura (m)

Clique em "Calcular IMC"

Veja seu resultado e classificação
